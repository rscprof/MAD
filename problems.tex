\section{Общие сведения}

Сборник содержит задания для семинарских занятий по курсу <<Разработка мобильных приложений>>.  
Задачник рассчитан на 32 часа семинарских занятий.

Структурно курс делится на две части:
\begin{enumerate}
    \item изучение языка Kotlin;
    \item изучение разработки на платформе Android.
\end{enumerate}

В практических и лабораторных работах предполагается использование языка Kotlin в средах
IntelliJ IDEA и Android Studio. При этом необходимо соблюдать
\href{https://kotlinlang.org/docs/coding-conventions.html}{Coding Conventions} (требования к стилю кода).

Перед сдачей работы добейтесь, чтобы среда не выдавала предупреждений
при запуске подпункта \textbf{Inspect Code} пункта меню \textbf{Analyze}.

Задачи в большей степени рассчитаны на освоение возможностей языка, а не
на алгоритмические сложности. Поэтому
осуществляйте написание кода в соответствии с заданием, а не с целью, чтобы
он просто работал.

Обратите внимание на то, что во всех заданиях необходимо проверять корректность входных данных: программа не должна \textit{падать}
ни в каких ситуациях.

\section{Проекты как замена заданиям семинаров}

Студент по согласованию с преподавателем может реализовывать мобильное приложение,
являющееся крупным проектом (его объём должен быть не меньше суммарного объёма заданий
семинаров).

Проект может реализовываться на Android (Kotlin), iOS (Swift) или Flutter (Dart).

В ходе реализации проекта нужно использовать следующие принципы:
покрытие UNIT- и UI-тестами, принципы Clean Architecture, MVVM, DI с использованием стандартных библиотек,
SOLID, функциональный подход в программировании. 

Используйте стандартные средства навигации (Navigation) или их аналоги на других платформах.

Код должен соответствовать стандартам кодирования, принятым в крупных организациях,
занимающихся разработкой программного обеспечения.

\section{Зачёт}

Зачёт -- накопительная оценка, состоящая из оценок за каждое задание (или альтернативный проект), двух итоговых заданий
с программированием прямо на парах, а также оценки за теорию (как минимум два письменных опроса на лекциях). 

Оценка суммируется следующим образом (каждая базовая оценка в 100-бальной шкале):

$$
\begin{array}{c}
0{,}2\times\textit{средняя оценка за практики}+\\
+0{,}5\times\textit{средняя оценка за письменные опросы}+\\+
0{,}3\times\textit{средняя оценка за практические офлайн-задания}
\end{array}
$$

Таблица перевода из 100-бальной шкалы в 4-бальную:

{\centering
\begin{tabular}{|c|c|}
    \hline
    оценка в 100-бальной шкале&оценка в 4-бальной шкале\\
    \hline
    0,00-50,00&2\\
    \hline
    50,00-67,99&3\\
    \hline
    68,00-83,99&4\\
    \hline
    84,00-100,00&5\\
    \hline
\end{tabular}

}

\section{Курсовая работа}

Выполнение курсовой работы состоит из следующих этапов (для типичной -- разработка продукта):

\begin{enumerate}
    \item выбор/согласование темы курсовой работы;
    \item разработка введения в курсовую работу (мотивировки, объект, предмет, методы);
    \item формулирование списка требований (спецификации);
    \item проектирование (выбор инструментальных средств, диаграммы UML);
    \item реализация (описание этапов реализации, использованных паттернов, проблем);
    \item тестирование (условно разделено с реализацией: UNIT- и UI-тестирование);
    \item формулирование заключения;
    \item оформление курсовой работы в соответствии с ГОСТ 7.32-2017 (списка литературы в соответствии с ГОСТ Р 7.0.100-2018).
\end{enumerate}

Выполнение курсовой работы состоит из следующих этапов (для исследовательской):

\begin{enumerate}
    \item выбор/согласование темы курсовой работы;
    \item формулирование гипотезы;
    \item разработка введения в курсовую работу (мотивировки, объект, предмет, методы);
    \item исследование литературы (теоретическая часть курсового проекта);
    \item разработка методики (дизайна) исследования;
    \item собственно исследование;
    \item разработка выводов по результатам исследования;
    \item формулирование заключения;
    \item оформление курсовой работы в соответствии с ГОСТ 7.32-2017 (списка литераутуры в соответствии с ГОСТ Р 7.0.100-2018).
\end{enumerate}

Оценка курсовой работы осуществляется по следующим критериям:
\begin{enumerate}
    \item выполнение работы в срок и по этапам;
    \item качество реализованного продукта/исследования;
    \item содержательно корректный текст пояснительной записки;
    \item правильность оформления пояснительной записки;
    \item качество защиты курсовой работы.
\end{enumerate}
