\section*{Вариант 1}

\begin{enumerate}
    \item \textbf{Программирование (Неравенства).} Напишите программу, которая решает неравенство $(x - a)(x - b) > 0$, где $a$ и $b$ — вещественные числа, вводимые пользователем. \\
    \textbf{Важно:} Необходимо реализовать проверку корректности входных данных (обработка случая $a = b$, нечисловых значений).
    
    \item \textbf{Программирование (Строки).} \textbf{Описание:} Напишите программу, которая читает с клавиатуры целое число $n$ ($1 \leq n \leq 1000$), затем $n$ строк (каждая длиной до 100 символов). Используя только StringBuilder для сборки результата, обработайте каждую строку согласно условию варианта, затем добавьте её в результат, если она удовлетворяет фильтру варианта. В конце добавьте общее количество символов в результате. Выводите на экран. Запрещено использовать String methods вроде reverse, replaceAll, format, join; все операции вручную через циклы и append/insert/delete. \\
    \textbf{Вариант задания:} Обработка: инвертировать строку; Фильтр: длина > 5. \\
    \textbf{Важно:} Требуется строгая проверка корректности входных данных (диапазон $n$, null-строки).
    
    \item \textbf{ООП (Класс).} Создайте класс, реализуйте методы \texttt{clone}, \texttt{equals}, \texttt{hashCode}, \texttt{toString}. В случае некорректности данных для инициализации вызывайте исключение. \\
    \textbf{Вариант задания:} Класс «Точка в 3D»: поля \texttt{x}, \texttt{y}, \texttt{z} (тип \texttt{double}).
    
    \item \textbf{Структуры данных (Список).} Реализуйте класс \texttt{MyLinkedList} (внутренний класс \texttt{Node}, вложенный итератор). Метод \texttt{print()} выводит элементы. Итератор возвращает элементы. \\
    \textbf{Основная задача:} Реализовать метод \texttt{remove(int value)}, удаляющий первое вхождение значения (обработка головы, хвоста, середины).
\end{enumerate}
