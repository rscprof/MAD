\subsection{Семинар <<Разработка первой программы на Kotlin>> (2 часа)}

Цель первых четырёх семинаров — обеспечить подготовку к выполнению заданий, 
нацеленных на освоение особенностей языка Kotlin. В первой работе
необходимо написать небольшую программу, чтобы убедиться в понимании
базовых конструкций языка (функция main, ветвления, циклы) и целого типа, а также обеспечить успешную настройку среды разработки.

При выполнении заданий обращайте внимание на использование специфических особенностей языка везде, где это возможно: 
if и when могут быть как операторами, так и частью выражений; фигурные скобки во многих случаях можно опускать;
точки с запятой почти никогда не используются, корректно выбирайте, как помечать переменные: ключевым словом var или val.

При выполнении работ обеспечивайте \textbf{оптимальность} предлагаемой программы как по скорости, так и по памяти. В
случае противоречия между двумя критериями, выбирайте алгоритм, который обеспечивает лучшее быстродействие.

В частности, это обозначает, что:
\begin{enumerate}
    \item Ввод осуществляется как строка, которую необходимо преобразовать в целое число.
    \item Далее вся работа должна вестись \textbf{исключительно с числом}, используя только арифметические операции (остаток от деления, целочисленное деление, циклы, условия).
    \item Использование строковых методов (включая преобразование числа обратно в строку) \textbf{запрещено}.
    \item Следует избегать сложных структур данных (списков, множеств, массивов).
\end{enumerate}

\textbf{Задание} %for+if+ввод+вывод+строки: 15 минут

Для данного неотрицательного целого числа (в пределах Int)
найдите указанный результат. Осуществите проверку 
корректности ввода. Оформите программу и устраните все warning.

\begin{enumerate}
\item Сумму чётных цифр
\item Сумму нечётных цифр
\item Произведение чётных цифр
\item Произведение нечётных цифр
\item Максимальную чётную цифру
\item Минимальную чётную цифру
\item Максимальную нечётную цифру
\item Минимальную нечётную цифру
\item Сумму цифр, кратных трём
\item Сумму цифр, не кратных трём
\item Произведение цифр, кратных трём
\item Произведение цифр, не кратных трём
\item Максимальную цифру, кратную трём
\item Минимальную цифру, кратную трём
\item Максимальную цифру, не кратную трём
\item Минимальную цифру, не кратную трём
\item Сумму цифр, стоящих на чётных позициях в числе (если нумеровать цифры с конца): для числа 1234 — ответ 4
\item Произведение цифр, стоящих на чётных позициях в числе (если нумеровать цифры с конца): для числа 1234 — ответ 3
\item Максимальную цифру среди стоящих на чётных позициях в числе (если нумеровать цифры с конца): для числа 1234 — ответ 3
\item Минимальную цифру среди стоящих на чётных позициях в числе (если нумеровать цифры с конца): для числа 1234 — ответ 1
\item Сумму цифр, стоящих на позициях в числе, номера которых кратны трём (если нумеровать цифры с конца): для числа 1234 — ответ 2
\item Произведение цифр, стоящих на позициях в числе, номера которых кратны трём (если нумеровать цифры с конца): для числа 1234 — ответ 2
\item Максимальную цифру среди стоящих на позициях в числе, номера которых кратны трём (если нумеровать цифры с конца): для числа 1234 — ответ 2
\item Минимальную цифру среди стоящих на позициях в числе, номера которых кратны трём (если нумеровать цифры с конца): для числа 1234 — ответ 2
\item Максимальную цифру среди стоящих на позициях в числе, номера которых кратны четырём (если нумеровать цифры с конца): для числа 1234 — ответ 1
\end{enumerate}
