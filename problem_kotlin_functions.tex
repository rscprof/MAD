\subsection{Практическая работа <<Функции Kotlin>> (2 часа)}

\textbf{Задание №1 (функции и лямбда-функции)}

Разработайте программу в соответствии с вашим вариантом. При этом:

\begin{itemize}
\item Основной алгоритм (без ввода-вывода) оформите в виде функции.
    \item В функцию передавайте исходное число и условие отбора цифр в виде лямбда-функции (например, проверка на чётность, нечётность, кратность трём, не кратность трём — в зависимости от варианта).
    \item Функция должна корректно работать при замене условия отбора — то есть быть универсальной.
\end{itemize}

\begin{enumerate}
\item Сумму чётных цифр
\item Сумму нечётных цифр
\item Произведение чётных цифр
\item Произведение нечётных цифр
\item Максимальную чётную цифру
\item Минимальную чётную цифру
\item Максимальную нечётную цифру
\item Минимальную нечётную цифру
\item Сумму цифр, кратных трём
\item Сумму цифр, не кратных трём
\item Произведение цифр, кратных трём
\item Произведение цифр, не кратных трём
\item Максимальную цифру, кратную трём
\item Минимальную цифру, кратную трём
\item Максимальную цифру, не кратную трём
\item Минимальную цифру, не кратную трём
\item Сумму цифр, стоящих на чётных позициях в числе (если нумеровать цифры с конца): для числа 1234 — ответ 4
\item Произведение цифр, стоящих на чётных позициях в числе (если нумеровать цифры с конца): для числа 1234 — ответ 3
\item Максимальную цифру среди стоящих на чётных позициях в числе (если нумеровать цифры с конца): для числа 1234 — ответ 3
\item Минимальную цифру среди стоящих на чётных позициях в числе (если нумеровать цифры с конца): для числа 1234 — ответ 1
\item Сумму цифр, стоящих на позициях в числе, номера которых кратны трём (если нумеровать цифры с конца): для числа 1234 — ответ 2
\item Произведение цифр, стоящих на позициях в числе, номера которых кратны трём (если нумеровать цифры с конца): для числа 1234 — ответ 2
\item Максимальную цифру среди стоящих на позициях в числе, номера которых кратны трём (если нумеровать цифры с конца): для числа 1234 — ответ 2
\item Минимальную цифру среди стоящих на позициях в числе, номера которых кратны трём (если нумеровать цифры с конца): для числа 1234 — ответ 2
\item Максимальную цифру среди стоящих на позициях в числе, номера которых кратны четырём (если нумеровать цифры с конца): для числа 1234 — ответ 1
\end{enumerate}

\textbf{Задание №2 (функции высшего порядка)}

\begin{enumerate}
    \item Создайте функцию, которая принимает произвольное количество функций с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int}, и возвращает новую функцию — сумму исходных. Для аргумента \( x \) результирующая функция возвращает сумму \( f_1(x) + f_2(x) + \dots + f_n(x) \).
    \item Создайте функцию, которая принимает произвольное количество функций с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int}, и возвращает новую функцию — произведение исходных. Для аргумента \( x \) результирующая функция возвращает произведение \( f_1(x) \cdot f_2(x) \cdot \dots \cdot f_n(x) \).
    \item Создайте функцию, которая принимает произвольное количество функций с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int}, и возвращает новую функцию — максимум исходных. Для аргумента \( x \) результирующая функция возвращает \( \max(f_1(x), f_2(x), \dots, f_n(x)) \).
    \item Создайте функцию, которая принимает произвольное количество функций с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int}, и возвращает новую функцию — минимум исходных. Для аргумента \( x \) результирующая функция возвращает \( \min(f_1(x), f_2(x), \dots, f_n(x)) \).
    \item Создайте функцию, которая по данной функции \( f: \texttt{Int} \to \texttt{Int} \) и целому числу \( n \) возвращает функцию, вычисляющую \( f \), применённую \( n \) раз: \( f(f(f(\dots f(x)\dots))) \).
    \item Создайте функцию, которая принимает произвольное количество функций без параметров, возвращающих \texttt{String}, и возвращает новую функцию без параметров, возвращающую конкатенацию результатов исходных функций.
    \item Создайте функцию, которая принимает произвольное количество функций с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int}, и возвращает новую функцию с аргументом \( x \) типа \texttt{Int}, возвращающую \textbf{индекс первой} функции (начиная с 0), имеющей \textbf{максимальное} значение при подстановке \( x \).
    \item Создайте функцию, которая принимает произвольное количество функций с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int}, и возвращает новую функцию с аргументом \( x \) типа \texttt{Int}, возвращающую \textbf{индекс первой} функции, имеющей \textbf{минимальное} значение при подстановке \( x \).
    \item Создайте функцию, которая принимает произвольное количество функций с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int}, и возвращает новую функцию с аргументом \( x \) типа \texttt{Int}, возвращающую \textbf{индекс последней} функции, имеющей \textbf{максимальное} значение при подстановке \( x \).
    \item Создайте функцию, которая принимает произвольное количество функций с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int}, и возвращает новую функцию с аргументом \( x \) типа \texttt{Int}, возвращающую \textbf{индекс последней} функции, имеющей \textbf{минимальное} значение при подстановке \( x \).
    \item Создайте функцию, которая по двум функциям с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int?} возвращает новую функцию — сумму исходных. Если хотя бы одна из функций возвращает \texttt{null}, результат также должен быть \texttt{null}.
    \item Создайте функцию, которая по двум функциям с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int?} возвращает новую функцию — произведение исходных. Если хотя бы одна из функций возвращает \texttt{null}, результат также должен быть \texttt{null}.
    \item Создайте функцию, которая по двум функциям с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int?} возвращает новую функцию — максимум исходных. Если хотя бы одна из функций возвращает \texttt{null}, результат также должен быть \texttt{null}.
    \item Создайте функцию, которая по двум функциям с параметром типа \texttt{Int} и возвращаемым значением типа \texttt{Int?} возвращает новую функцию — минимум исходных. Если хотя бы одна из функций возвращает \texttt{null}, результат также должен быть \texttt{null}.
    \item Создайте функцию, которая по двум функциям \( f \) и \( g \) (обе: \texttt{Int} → \texttt{Int?}) возвращает функцию, вычисляющую композицию \( f(g(x)) \). Если \( g(x) = \texttt{null} \), то результат — \texttt{null}.
    \item Создайте функцию, которая по функции \( f: \texttt{Int} \to \texttt{Int} \) и целому числу \( n \) возвращает новую функцию, принимающую массив из \( n \) элементов типа \texttt{Int} и возвращающую массив результатов применения \( f \) к каждому элементу.
    \item Создайте функцию, которая по данному массиву целых чисел возвращает функцию без параметров, которая при каждом вызове последовательно возвращает элементы массива. После исчерпания элементов возвращает \texttt{null}.
    \item Создайте функцию, которая по функции \( f: \texttt{Int} \to \texttt{Int} \) возвращает функцию без параметров, которая при каждом вызове последовательно возвращает \( f(1) \), \( f(2) \), \( f(3) \), и так далее.
    \item Создайте функцию, которая по данному массиву целых чисел возвращает функцию без параметров, которая при каждом вызове последовательно возвращает элементы массива в обратном порядке. После исчерпания элементов возвращает \texttt{null}.
    \item Создайте функцию, которая по данной строке возвращает функцию без параметров, которая при каждом вызове последовательно возвращает символы строки. После исчерпания символов возвращает \texttt{null}.
    \item Создайте функцию, которая по данной строке возвращает функцию без параметров, которая при каждом вызове последовательно возвращает символы строки в обратном порядке. После исчерпания символов возвращает \texttt{null}.
    \item Создайте функцию, которая принимает произвольное количество функций с параметром типа \texttt{Float} и возвращаемым значением типа \texttt{Float}, и возвращает новую функцию — среднее арифметическое исходных: \( \frac{f_1(x) + f_2(x) + \dots + f_n(x)}{n} \).
    \item Создайте функцию, которая принимает произвольное количество функций с параметром типа \texttt{Float} и возвращаемым значением типа \texttt{Float}, и возвращает новую функцию — среднее квадратическое исходных: \( \sqrt{\frac{f_1(x)^2 + f_2(x)^2 + \dots + f_n(x)^2}{n}} \).
    \item Создайте функцию, которая принимает произвольное количество функций с параметром типа \texttt{Float} и возвращаемым значением типа \texttt{Float}, и возвращает новую функцию — среднее геометрическое исходных: \( \sqrt[n]{f_1(x) \cdot f_2(x) \cdot \dots \cdot f_n(x)} \). Предполагается, что все значения положительны.
    \item Создайте функцию, которая по функции \( f: \texttt{Float} \to \texttt{Float} \) и числу \( x \) возвращает функцию без параметров, которая при каждом вызове последовательно возвращает \( f(x) \), \( f(f(x)) \), \( f(f(f(x))) \), и так далее.
\end{enumerate}
