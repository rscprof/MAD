\subsection{Семинар <<Работа с внешними сервисами RestAPI>> (2 часа)}

\paragraph{Общие требования ко всем заданиям}

\paragraph{Задания}

Реализуйте клиент для одного из следующих REST-API. Каждое задание предполагает:
\begin{itemize}
    \item наличие хотя бы одного параметризованного запроса;
    \item отображение результата в UI
\end{itemize}

Если сайт, указанный в вашем варианте, не работает или не доступен, замените его на
другой аналогичный сайт, но при этом сайты-заменители у разных студентов совпадать не
должны (выбирайте сайты-заменители полностью независимо друг от друга).

    \item \textbf{RestCountries API} — поиск стран по языку (\texttt{lang=ru}). \
    \url{https://restcountries.com/}\item \textbf{RestCountries API} — поиск стран по валюте (\texttt{currency=USD}). \\
\url{https://restcountries.com/}

\item \textbf{RestCountries API} — поиск стран по региону (\texttt{region=Europe}). \\
\url{https://restcountries.com/}

\item \textbf{RestCountries API} — поиск стран по субрегиону (\texttt{subregion=Eastern Europe}). \\
\url{https://restcountries.com/}

\item \textbf{RestCountries API} — поиск стран по региональному блоку (\texttt{regionalbloc=EU}). \\
\url{https://restcountries.com/}

\url{https://api.met.no/weatherapi/airqualityforecast/0.1/}

\item \textbf{Met.no Location Forecast API} — прогноз погоды (температура, осадки, ветер) по координатам из фиксированного списка. \\

\url{https://www.tvmaze.com/api}

\url{https://www.tvmaze.com/api}

\item \textbf{TVMaze API} — расписание эфиров по дате и стране. \\
\url{https://www.tvmaze.com/api}

\item \textbf{Nager.Date API} — получение списка праздников по году и коду страны (например, \texttt{US}). \\
\url{https://date.nager.at/api/v3/}

\item \textbf{Math.js API} — упрощение математического выражения (например, \texttt{2x + 3x}). \\
\url{https://api.mathjs.org/}

\item \textbf{Tronald Dump API} — поиск цитат по ключевому фрагменту текста. \\
\url{https://api.tronalddump.io/}

\item \textbf{Currency API} — получение курсов обмена относительно заданной валюты (например, \texttt{usd}). \\

\item \textbf{Nationalize.io API} — прогноз национальности по имени с вероятностями. \\
\url{https://api.nationalize.io/}
