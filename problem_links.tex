\subsection{Лабораторная работа <<Интеграция с экосистемой Android: deep links, обмен данными>>}

\textbf{Цель работы:} Расширить Compose-приложение механизмами взаимодействия с другими приложениями и внешними источниками: приём данных через ссылки и системное меню «Поделиться», отправка результатов.

\begin{itemize}
    \item Приложение должно обрабатывать \textbf{Deep Links} (схема \texttt{myapp://}) и HTTPS-ссылки для мгновенного открытия контента (заполнения формы поиска)
    \item Приложение должно выступать получателем данных через системное меню «Поделиться» (\textbf{Share Target}) с обработкой текста (содержащего URL или текст для поиска)
    \item Должна быть реализована отправка результатов в другие приложения через \texttt{Intent.ACTION\_SEND}.
    \item Обязательна базовая валидация внешних данных.
\end{itemize}
