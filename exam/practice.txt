\begin{enumerate}  
\item Для неотрицательного целого числа — сумма его цифр;  
\item Для строки из слов — первый символ первого максимально длинного слова с нечётной длиной;

\item По номеру $n$ — $n$-е число Фибоначчи (без рекурсии с экспоненциальной сложностью).  
\end{enumerate}

\item По заданному числу Фибоначчи найдите его номер в последовательности (не используйте факты, которые вы не можете доказать самостоятельно; допускается только линейное или логарифмическое решение без предварительного знания индекса).
\end{enumerate}
Приложение должно позволять выбирать задачу, вводить данные, проверять корректность ввода, выводить результат и повторять выполнение. Все функции должны быть чистыми.
