\subsection{Семинары 
<<Использование библиотек для поддержки Dependency Injection и Clean Architecture>> 
(6 часов)}

Используйте Hilt для внедрения Dependency Injection в проект, созданный 
на прошлом семинаре. Приведите проект в соответствие принципам Clean Architecture
(выделить View, ViewModel, UseCases, Model, Repositories, DataSources, DI).

Дополните Unit-тесты и UI-тесты для полного покрытия.

Для хранения информации в Android-приложении (и только в нем) используйте ROOM (соответственно у вас будет три репозитория -- 
тот, что был реализован в консоли; ROOM-репозиторий и Mock).
